En este proyecto, el usuario abandona su forma humana para convertirse en una onda de luz. El objetivo es navegar por el espacio profundo, aproximándose al agujero negro Capers Irdz9, experimentando de primera mano cómo la gravedad extrema distorsiona la realidad y la trayectoria de la luz.
+4

🎯 Objetivos Educativos
A través de un enfoque lúdico, la aplicación busca enseñar conceptos clave de la física:


Naturaleza de la luz: Comportamiento y velocidad constante en el vacío.


Relatividad General: La curvatura del espacio-tiempo y la desviación gravitacional.
+2


Anatomía de un Agujero Negro: Exploración del Horizonte de Sucesos y la Singularidad.
+1

🛠️ Características Técnicas
Motor: Unity 2022.3 LTS con Universal Render Pipeline (URP) para optimización visual y rendimiento en dispositivos móviles.

Plataforma: Diseñado para Meta Quest utilizando el XR Interaction Toolkit.


Locomoción: Sistema de movimiento a escala de habitación (room-scale movement) donde el entorno se desplaza para simular velocidad constante y minimizar el mareo por movimiento (motion sickness).
+1


Visuales: Uso de Shaders avanzados para representar la lente gravitacional y el disco de acreción.
+1

🚀 Estructura de la Experiencia

Sala de Contexto: Una habitación introductoria donde se elige el tipo de onda de luz y se recibe información teórica básica.


Navegación Espacial: Viaje interactivo sorteando cuerpos celestes que afectan la trayectoria mediante atracción física.
+1


Aproximación a Capers Irdz9: Fase final donde se visualizan los efectos más extremos de la gravedad cerca del horizonte de sucesos.
+1


Proyecto desarrollado para estudiantes de la Fundación Universitaria Konrad Lorenz.
