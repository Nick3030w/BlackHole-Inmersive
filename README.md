## 🌌 Descripción

**Black Hole Immersive Experience** es un videojuego educativo desarrollado en **Unity 2022.3** como proyecto de grado. El jugador embarca en un viaje al interior de un agujero negro, y durante el trayecto el juego presenta conceptos científicos reales de forma visual, interactiva y envolvente.

La experiencia combina narrativa espacial con mecánicas de aprendizaje para enseñar temas complejos de una forma accesible e inmersiva.

---

## 🧠 Contenido educativo

El juego aborda los siguientes temas científicos a través de la experiencia de juego:

| Área | Temas cubiertos |
|---|---|
| ⚛️ Física | Gravedad extrema, fuerzas tidales, aceleración relativista |
| 🌀 Relatividad General | Curvatura del espacio-tiempo, dilatación temporal, horizonte de eventos |
| 💡 Óptica y Luz | Comportamiento de la luz cerca de un agujero negro, lente gravitacional |
| 🔭 Astronomía | Estructura de un agujero negro (singularidad, horizonte, ergosfera), tipos de agujeros negros |

## ⚙️ Cómo abrir el proyecto

**Requisitos previos:**
- Unity Hub instalado
- Unity versión **2022.3.x LTS**

**Pasos:**

**1. Clona el repositorio**
```bash
git clone https://github.com/Nick3030w/Black-Hole-Immersive-Experience.git
```

**2. Abre Unity Hub**
- Click en **"Add project from disk"**
- Selecciona la carpeta del repositorio clonado

**3. Abre el proyecto**
- Asegúrate de tener instalada la versión **Unity 2022.3 LTS**
- Abre la escena principal desde `Assets/Scenes/`
